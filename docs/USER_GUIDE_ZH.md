# ODW Vault 使用指南（写给非技术用户）

> ODW Vault 是一个运行在**自己电脑/自己公司服务器**上的"AI 知识库助手"。
> 你把公司的文档放进它的资料库，然后像聊天一样向它提问。
> 它回答时还会告诉你答案来自哪份文件的哪一页，方便你核对。
>
> **最重要的一点：所有文档和所有问答都只发生在你自己的电脑上，不会发送到任何外部网站。**

## 1. 它能帮我做什么

- **快速找资料**：不用一个个翻文件夹，直接问"报销流程是什么？"，它会帮你从几百份文档里找出答案。
- **总结文档**：可以问"总结一下这份合同的重点"。
- **多语言**：中文、英文的文档都可以，提问也可以中英文混用。
- **答案有出处**：每条答案下面会列出"来源卡片"，标明来自哪个文件、第几页，点击可以核对原文。

它**不能**做的事：
- 它只回答**资料库里有的内容**。资料库里没有的信息，它会明确说"资料中没有足够信息"，而不会瞎编。
- 它不能上网搜索，也不能访问资料库文件夹之外的文件。

## 2. 第一次使用前的准备

> 这一节**只需要做一次**，而且通常由技术同事完成。
> 如果你拿到电脑时已经能正常使用（见第 3 节），可以跳过这一节。

准备清单（macOS 为例）：

| 需要安装的东西 | 作用 | 谁来装 |
|---|---|---|
| Python 3.11 运行环境 | 程序运行的基础 | 技术同事 |
| [Ollama](https://ollama.com/download) | 本地 AI 引擎，负责读文档和写答案 | 技术同事（注意：要用官网安装脚本，不要用 App Store/Homebrew 旧版本） |
| ODW Vault 程序本体 | 就是本系统 | 技术同事 |

安装完成后，技术同事会执行一次"初始化"，之后你每天要做的只有第 3 节里的一两条命令。

## 3. 每天怎么打开它

**第 1 步：启动 AI 引擎（Ollama）**

打开"终端"（Terminal）应用，输入：

```
ollama serve
```

看到持续滚动的日志就表示成功了。**这个窗口不要关**，可以把它最小化。

**第 2 步：启动 ODW Vault**

再开一个新的终端窗口，输入：

```
cd 项目文件夹位置
.venv/bin/python cli.py ui
```

看到类似这样的提示就表示成功：

```
* Running on local URL:  http://127.0.0.1:7900
  ODW Vault UI: http://127.0.0.1:7860
```

**第 3 步：在浏览器里打开**

打开浏览器（Safari 或 Chrome 都可以），访问界面上显示的 `ODW Vault UI` 网址（一般是 `http://127.0.0.1:7860`）。

> 用完之后：直接关闭浏览器页面即可。下班想全部关掉时，在两个终端窗口里分别按 `Ctrl + C`。

## 4. 认识界面

打开页面后，主要分三块：

```
┌────────────┬──────────────────────────────┐
│  左侧栏     │        中间主区域             │
│            │                              │
│ 会话历史    │   欢迎语 + 提问输入框          │
│ （点标题可  │   （下面有几个快捷问题按钮）    │
│ 回看旧的    │                              │
│ 问答）      │   底部：📁 文件夹筛选  ⚙ 设置  │
└────────────┴──────────────────────────────┘
```

- **左侧栏（Conversations）**：每次提问都会自动保存成一个会话，点标题可以回看；点标题旁的 `×` 可以删除。顶部搜索框可以按关键词找历史问答。
- **`+ New Chat` 按钮**：开始一个新话题。**换了新话题建议点一下**，这样 AI 不会把上一个话题的内容带到新对话里。
- **📁 文件夹下拉框（All folders）**：默认"所有文件夹"。如果你只想在某个范围的文档里找答案（比如只在 `docs` 文件夹里），从这里选一个文件夹，提问就只查这个范围。展开树状列表可以看到每个文件夹里的文件和索引状态。
- **⚙ 设置按钮**：打开设置面板，里面有"知识库状态"和"模型设置"（模型设置一般由管理员维护，**不建议随便改动**）。

## 5. 怎么提问

在输入框里用平常说话的方式打字即可，按回车发送。几个实用建议：

**问得具体一点，效果更好**

- ✅ "员工差旅报销的审批流程是什么？需要哪些单据？"
- ❌ "报销"（太短，AI 要猜你想问什么）

**让 AI 总结 / 对比 / 找清单**

- "总结一下 XX 项目文档的主要结论"
- "对比新旧两版流程有什么差别"
- "资料库里有哪些和信息安全相关的文件？"

**看懂回答**

- 回答中的 **[1]、[2]** 这样的角标对应下方的来源卡片，鼠标放上去或点击可以定位到来源。
- 来源卡片显示了**文件路径、页码、原文摘录**。重要决策请务必点开核对原文。
- 如果回答说"没有足够的信息"，说明资料库里确实没有相关内容——可以试着换个说法，或者确认相关文档是否已经添加进资料库（见第 6 节）。

**支持中文、英文、中英混合**提问和文档。

## 6. 怎么添加新文档

有两种方式把文档放进资料库：

**方式 A：请管理员把文件放进资料文件夹（推荐，适合批量）**

资料文件夹的位置由管理员设定（本项目的默认位置叫 `SourceData`）。把文件拷贝进去后，按第 7 节的操作点一次"⚡ Sync Now"即可。

**方式 B：在设置面板里上传**

1. 点右下角 **⚙ 设置按钮**；
2. 找到"上传文件（Upload Files）"区域；
3. 点击选择文件（可以多选），等待上传完成。

> 目前上传的文件会放在资料库根目录。需要归档到子文件夹的，请交给管理员整理。

**上传/拷贝之后，必须做一次"同步"，新文档才能被搜索到：**

1. 在设置面板中找到"知识库状态（Knowledge Base Status）"卡片；
2. 点击 **⚡ Sync Now** 按钮；
3. 等待进度提示完成（文档多时可能需要几分钟到更久，期间可以最小化窗口做别的事）；
4. 完成后点 **↻ Refresh** 刷新状态。

同步时电脑在做什么？它在**后台**完成四件事：读取文件内容 → 把内容切成小段 → 为每段生成"指纹"（向量化）→ 存入本地检索库。所以第一次同步大量文档时会比较慢，之后就快了。

## 7. 知识库状态面板怎么看

设置面板里的"知识库状态"长这样（数字是示例）：

```
进度：  ████████░░░░░░░░  37.5% (5 failed)
[8] 总文件  [3] 已索引  [0] 待处理  [48] 文本块  [5] 失败  [2] 文件夹
✅ docs      3/3 embedded
⏳ SourceData  0/5 embedded
上次同步：2026-09-11 21:14
```

各数字的含义：

| 显示 | 含义 |
|---|---|
| **总文件** | 资料库里的文件总数 |
| **已索引（embedded）** | 已经"读完并建好检索指纹"的文件数——只有这些能被搜到 |
| **待处理（pending）** | 还在排队等待处理的文件 |
| **失败（failed）** | 处理失败的文件数。**进度条会变红提示你** |
| **文件夹列表** | 每个文件夹的进度：✅ 完成 / ⏳ 进行中 / ⬜ 未开始 |

**如果出现"失败"怎么办？**

- 最常见原因：**AI 引擎（Ollama）没有启动**。先按第 3 节启动 Ollama，然后回到面板再点一次 **⚡ Sync Now**，之前失败的文件会自动重试。
- 如果反复失败，把失败信息（面板会显示"Last sync failed: ..."）截图发给技术同事。
- 同步过程中不用干等：面板会每 10 秒自动刷新，同步完成时会弹出提示。

## 8. 常见问题与解决办法

**Q1：界面顶部/设置里显示"🔴 Ollama down"是什么意思？**
A：AI 引擎没启动。按第 3 节第 1 步启动 Ollama；显示"🟢 Ollama OK"后即可正常提问。

**Q2：提问后报错，或一直没反应？**
A：按顺序检查：① Ollama 是否启动；② 是否刚刚同步完大量文档（第一次同步很耗资源，等它完成再提问）；③ 还不行就把页面刷新（Cmd+R）再试一次。

**Q3：上传文件后搜索不到新内容？**
A：上传后必须点一次 **⚡ Sync Now**。同步完成、状态里该文件显示为"已索引"后才能搜到。

**Q4：在 macOS 上启动时提示"Database is READ-ONLY"？**
A：这是 macOS 对拷贝过来的文件加的"隔离标记"导致的。请技术同事在终端执行：
```
xattr -c corpus.db corpus.db-wal corpus.db-shm
```
然后重新启动程序。

**Q5：两个人可以同时用吗？**
A：可以，多人在各自浏览器里打开同一个地址即可，互不干扰。

**Q6：回答里的 [1][2] 角标点不动？**
A：角标需要页面完全加载后才能点击；刷新一次页面通常可以解决。

**Q7：忘记语法/命令了怎么办？**
A：日常使用只需要记住第 3 节的两条命令和第 6 节的"上传 → Sync Now"流程，其余都可以点界面完成。

## 9. 数据安全须知

- **数据不出门**：文档、提问、回答全部保存在本机/本公司服务器上，运行过程中**不会连接外部网络**。
- **可选的云端模型**：如果管理员在"模型设置"里配置了云端服务商（OpenAI、DeepSeek 等），那么提问内容会发送给**该服务商**。未配置时默认全本地，请与管理员确认贵司的策略。
- **删除要谨慎**：删除文件（设置面板中的 Delete）会同时从资料库和检索库中删除，删除前请确认不再需要。
- **建议定期备份**：整个项目文件夹（含 `corpus.db` 和资料文件夹）拷贝一份即可完成备份。
